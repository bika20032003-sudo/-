# منظومة متابعة الكسارات والوقود والشرشور
### جهاز تنفيذ مشروعات المواصلات

منظومة متكاملة وشاملة لمتابعة وتشغيل الكسارات، إدارة الوقود والمحروقات، ومتابعة معدات إنتاج وتوريد الشرشور لمشروعات الطرق والبنية التحتية.

## 🌟 مميزات المنظومة
- **لوحة مؤشرات تفاعلية (Interactive Dashboard)**: إحصائيات فورية للمخزون، الإنتاج اليومي، واستهلاك الوقود.
- **إدارة وتقارير الكسارات**: متابعة حالة الكسارات والإنتاجية ومعدلات التشغيل.
- **إدارة ومتابعة الوقود (Fuel Management)**: رصد الاستهلاك اليومي للآليات ومخزون الخزانات الرئيسية.
- **إدارة توريد وإنتاج الشرشور**: تتبع الكميات المنتجة والموزعة لمواقع العمل.
- **نظام التنبيهات الذكي**: إشعارات بانخفاض المخزون أو متطلبات الصيانة الدورية.
- **دعم التقارير والتصدير**: إمكانية تصدير التقارير بصيغ PDF و Excel وطباعتها بسهولة.
- **نظام مصادقة وأذونات موحد**: إدارة الصلاحيات للمهندسين والمشرفين ومدراء المواقع.

---

## 🛠 التقنيات المستخدمة
- **الواجهة الأمامية (Frontend)**: React 18, Vite, Lucide Icons, Recharts, CSS3
- **الخادم الخلفي (Backend)**: Node.js, Express 5, CORS, RESTful APIs
- **قاعدة البيانات (Database)**: MySQL (مع دعم نظام التخزين المؤقت فائق السرعة FastPersistentStore)

## 🚀 طريقة التشغيل السريع

### 1. المتطلبات الأساسية
- Node.js (v18+)
- npm أو yarn

### 2. تثبيت الحزم
```bash
# تثبيت حزم الواجهة الأمامية
npm install

# تثبيت حزم الخادم الخلفي
cd server
npm install
cd ..
```

### 3. إعداد متغيرات البيئة
قم بإنشاء ملف `.env` داخل مجلد `server/` أو انسخ من `.env.example`:
```bash
PORT=5000
DATABASE_URL="mysql://root:@localhost:3306/crusher_db"
```

### 4. تشغيل المنظومة
يمكنك تشغيل المنظومة بنقرة واحدة باستخدام ملف:
```cmd
تشغيل_المنظومة.bat
```
أو يدوياً عبر سطر الأوامر:
```bash
# في نافذة Terminal أولى (تشغيل الخادم الخلفي):
cd server
npm start

# في نافذة Terminal ثانية (تشغيل الواجهة الأمامية):
npm run dev
```

المنظومة ستكون متاحة على:
- الواجهة: `http://localhost:3000`
- الخادم: `http://localhost:5000`
