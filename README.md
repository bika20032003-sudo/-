## 1. 🛡️ منظومة وزارة الداخلية الموحدة

نظام إلكتروني متكامل لوزارة الداخلية مبني بأحدث تقنيات الويب:
- **الواجهة الأمامية (Frontend):** React + Vite + Lucide Icons + Cairo Font.
- **الخادم الخلفي (Backend):** Node.js + Express.js + JWT Authentication + BCrypt.
- **قاعدة البيانات (Database):** MySQL مع دعم التهيئة التلقائية (`schema.sql`) ووضع المحاكاة الآمن.

### 🚀 تشغيل منظومة وزارة الداخلية محلياً:
- انقر نقراً مزدوجاً على: `start_all.bat` أو `تشغيل_منظومة_وزارة_الداخلية.bat`
- الواجهة: `http://localhost:5173`
- الخادم الخلفي: `http://localhost:5050`

### 🔑 بيانات تسجيل الدخول الافتراضية:
- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin`
*(أو استخدم زر "تعبئة تلقائية" في شاشة الدخول)*

## 2. 🛣️ مشروع صيانة وتطوير طريق أوباري – غات

بوابة رقمية تفاعلية لمشروع طريق أوباري – غات الاستراتيجي بطول **360 كم** في الجنوب الليبي تحت إشراف **جهاز تنفيذ مشروعات المواصلات** ضمن خطة **عودة الحياة**:
- تتبع مسار الطريق والخرائط التفاعلية
- مراحل المشروع السبع والشركاء الوطنيين والدوليين
- مؤشرات الإنجاز والأثر التنموي والأمني والاقتصادي
- تقنيات متقدمة في الرسوميات والتفاعل والانسيابية

### 🚀 تشغيل موقع طريق أوباري – غات محلياً:
- انقر نقراً مزدوجاً على: `تشغيل_موقع_طريق_أوباري_غات.bat`
- أو عبر الأوامر:
  ```bash
  cd ubari-ghat-road
  npm install
  npm run dev
  ```
- الموقع متاح على: `http://localhost:3000`
