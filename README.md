# منظومة وزارة الداخلية - دولة ليبيا 🇱🇾
### مديرية أمن أوباري | منظومة العمليات والتحكم الأمني الموحدة

نظام إلكتروني سيادي متكامل لإدارة القوة العمومية، العمليات الأمنية، الرسوم البيانية للأقسام، والمراسلات الرسمية.

## 🌐 رابط المعاينة والتشغيل المباشر (GitHub Pages)

- 🛡️ **رابط منظومة وزارة الداخلية**: [https://bika20032003-sudo.github.io/-/](https://bika20032003-sudo.github.io/-/)

---

## 🛠️ التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):** React + Vite + Lucide Icons + خط Cairo الرسمي.
- **الخادم الخلفي (Backend):** Node.js + Express.js + JWT Authentication + BCrypt.
- **قاعدة البيانات (Database):** MySQL مع دعم التهيئة التلقائية (`schema.sql`) ونظام المحاكاة الآمن.

---

## 🚀 تشغيل منظومة وزارة الداخلية محلياً:

- انقر نقراً مزدوجاً على: `start_all.bat` أو `تشغيل_منظومة_وزارة_الداخلية.bat`
- **الواجهة:** `http://localhost:5173`
- **الخادم الخلفي:** `http://localhost:5050`

---

## 🔑 بيانات تسجيل الدخول الافتراضية:
