# منظومة وزارة الداخلية الموحدة (MERN Full-Stack + MySQL)

نظام إلكتروني متكامل لوزارة الداخلية مبني بأحدث تقنيات الويب:
- **الواجهة الأمامية (Frontend):** React + Vite + Vanilla CSS + Lucide Icons + خط القاهرة (Cairo).
- **الخادم الخلفي (Backend):** Node.js + Express.js + JWT Authentication + BCrypt.
- **قاعدة البيانات (Database):** MySQL مع دعم التهيئة التلقائية (`schema.sql`) ونظام اتصال مرن مع وضع المحاكاة الآمن عند عدم توفر خادم MySQL محلياً.

---

## 🚀 كيفية التشغيل السريع

يمكنك تشغيل المشروع بالكامل بنقرة واحدة عبر:
- النقر المزدوج على ملف: `start_all.bat`

أو يدوياً:
1. **تشغيل المخدم الخلفي:**
   ```bash
   cd server
   npm start
   ```
   (يعمل على المنفذ `http://localhost:5050`)

2. **تشغيل الواجهة الأمامية:**
   ```bash
   cd client
   npm run dev
   ```
   (تعمل على المنفذ `http://localhost:5173`)

## 🔑 بيانات تسجيل الدخول الافتراضية
- **اسم المستخدم / البريد:** `admin`
- **كلمة المرور:** `admin`
- تتوفر أيضاً ميزة **"تعبئة تلقائية"** بزر واحد في شاشة تسجيل الدخول للتجربة الفورية.

## 🗄️ إعداد قاعدة بيانات MySQL
ملف المخطط البرمجي متوفر في:
- [`server/src/schema.sql`](file:///d:/وزارة%20الداخلية/server/src/schema.sql)

بيانات الاتصال بقاعدة البيانات في ملف:
- [`server/.env`](file:///d:/وزارة%20الداخلية/server/.env)

```env
PORT=5050
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=
DB_NAME=interior_ministry_db
```
