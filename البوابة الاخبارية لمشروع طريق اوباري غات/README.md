# البوابة الإخبارية والمنظومة التنفيذية لمشروع طريق أوباري – غات (360 كم)
### Transportation Projects Execution Authority – Ubari to Ghat Highway Executive Portal

![مشروع صيانة وتأهيل طريق أوباري – غات](public/agency_logo.png)

---

## 📌 نبذة عن المشروع
منظومة وبوابة تفاعلية ذكية ومتقدمة لمتابعة سير الأعمال وإدارة المشاريع الهندسية لمشروع **صيانة وتأهيل طريق أوباري – غات بطول 360 كيلومتراً**، الشريان الاستراتيجي الحيوي الرابط بين مدن وقرى الجنوب الغربي الليبي، تحت إشراف **جهاز تنفيذ مشروعات المواصلات** وضمن **مبادرة عودة الحياة**.

---

## ✨ المميزات الرئيسية للمنظومة

1. **مركز القيادة واللوحة التنفيذية (Executive Command Center):**
   - متابعة مؤشرات الأداء الرئيسية (KPIs)، ونسب الإنجاز الفعلي والمستهدف.
   - إدارة الشركات الوطنية المنفذة وائتلافات الرصف والأسطول الميداني.
   - إدارة المستخلصات المالية والعقود وتقارير ضبط الجودة والمختبرات.

2. **الخريطة التفاعلية ومحطات مسار الـ 360 كم:**
   - استعراض حي لمحطات وقطاعات الطريق الأربعة من أوباري حتى غات.
   - إمكانية إضافة وتعديل وحذف محطات الخريطة مباشرة من لوحة التحكم مع ربط الإحداثيات بنظام ملاحة Google Maps.

3. **شريط الأخبار والبيانات الميدانية العاجلة (Live Ticker):**
   - شريط إخباري متحرك يعكس آخر مستجدات العمل الميداني وصب الأسفلت واختبارات الكثافة.
   - تحكم كامل في إضافة الأخبار أو تعديلها أو حذفها عبر لوحة الإدارة.

4. **تتبع الطقس الميداني وأسعار الصرف:**
   - قياسات حية ومحدثة للحرارة، الرياح، الرطوبة، ومدى الرؤية الأفقية على مسار الطريق الصحراوي.
   - النشرة الرسمية اليومية لأسعار صرف العملات الأجنبية الصادرة عن مصرف ليبيا المركزي.

5. **المواصفات الفنية الشاملة لطبقات الطريق:**
   - كشط وتدوير طبقات الرصف القائمة بتقنية FDR.
   - طبقة الأساس الحبيبي والرش بمادة MCO.
   - الطبقة الأسفلتية السطحية المعالجة بالبوليمر بسُمك 6 سم وعرض 9 أمتار.
   - شبكة العبّارات الخرسانية لتصريف مياه السيول والحماية من الانجراف.
   - العلامات والشواخص الإرشادية وعواكس المسار وتخطيط الطريق الحراري.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):** React 18, Vite, Tailwind CSS, Lucide React Icons.
- **التفاعل والتأثيرات (Animations):** CSS3 Animations, 3D Canvas / Horizon Telemetry.
- **الخلفية وقاعدة البيانات (Backend & DB):** Node.js / Express, SQLite3 (WAL Mode), RESTful API.
- **الخطوط:** Cairo, Amiri (Google Fonts) مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL) وثنائي اللغة (عربي / English).

## 🚀 تشغيل المشروع محلياً (Getting Started)

### المتطلبات الأساسية:
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- مدير الحزم `npm`

### خطوات التثبيت والتشغيل:

```bash
# 1. استنساخ المستودع
git clone https://github.com/bika20032003-sudo/-.git
cd -

# 2. تثبيت الحزم والمكتبات
npm install

# 3. تشغيل الخادم والواجهة في وضع التطوير
npm run dev
```

لفتح المنظومة في المتصفح:
- **البوابة العامة:** `http://localhost:3000`
- **خادم الواجهة الخلفية (Backend API):** `http://localhost:5000`
